# 🛒 Plataforma Web de Contratação de Serviços

Interface onde o cliente navega na vitrine e contrata, e o admin gerencia os pedidos.

## 🔗 Demonstração

O site está publicado e pode ser acessado pelo link abaixo: [👉 CLIQUE AQUI PARA ACESSAR O SITE](https://marketplaceweb-futurodigital.vercel.app/)

## 💻 Sobre o Projeto

A Plataforma Web de Contratação de Serviços é uma aplicação frontend desenvolvida em React que permite:

👤 Clientes navegarem pela vitrine de serviços

🛍️ Visualizarem detalhes e contratarem serviços

📦 Acompanharem o status dos pedidos

🛠️ Administradores gerenciarem e aprovarem solicitações

A aplicação consome uma API criada no JSONBin para simulação de backend.

## 🛠️ Tecnologias

Para este projeto, utilizei as seguintes tecnologias:

⚛️ React (com Vite)

🧭 React Router DOM

🎨 CSS

🌐 Fetch API

☁️ Vercel (Deploy)

🗄️ JSONBin (API Mock)
